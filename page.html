The initial processing is O(N^3), but because the data structure is composed of a binary search tree, the drawing order calculation process is O(N), and the collision detection and shadow drawing processes are O(logN). To be more specific, the lightweight binary space partitioning performs lightweight drawing order calculation processing by dividing on planes parallel to the x, y, and z axes, and further reduces the amount of processing for drawing order calculation processing, collision detection, and shadow drawing position calculation by using a form close to a balanced binary search tree. And the high-speed rectangular parallelepiped drawing simplifies the processing by using vector calculations, reducing the number of vertices calculated in conventional rectangular parallelepiped drawing to 8. In addition, the backface culling process is made lighter by using the property that the faces of the rectangular parallelepiped are parallel to the x, y, and z axes.
